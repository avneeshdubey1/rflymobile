# Pilot Field Navigation Map

## Top-Level Destinations (Bottom Tabs)
1. **Work:** `PF-03 Work list` (Default)
2. **Sync:** `PF-12 Sync status`
3. **Profile:** `PF-13 Profile and security`

## Transactional Flows
- **Assignment Flow:** `PF-03` -> `PF-04` (Detail)
- **Readiness Flow:** `PF-04` -> `PF-06` (Select Copilot) -> `PF-07` (Confirm) -> `PF-04`
- **Action Flow:** `PF-04` -> `PF-05` (Accept) OR `PF-08` (Start) -> `PF-09` (Active)
- **Reporting Flow:** `PF-09` -> `PF-10` (Report Issue) -> `PF-09`
- **Completion Flow:** `PF-09` -> `PF-11` (Complete) -> `PF-03`
- **Error/System:** `PF-01` (Login), `PF-14` (Upgrade Required)
