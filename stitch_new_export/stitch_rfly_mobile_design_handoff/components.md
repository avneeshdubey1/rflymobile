# RFLY Component Library

## 1. Buttons
- **Primary:** Full-width, Safety Orange background, White text.
- **Secondary:** Outlined Navy or Navy text on light surface.
- **Destructive/Issue:** Outlined Red or Red text.
- **Size:** Minimum height 48dp.

## 2. Fields & Inputs
- **Text Input:** Outlined, 16px text, 12px label.
- **Selectors:** Controlled lists only (no free-form text unless specified for notes).

## 3. Feedback & Status
- **Status Chips:** Small badges with background/text pairing (e.g., Green/White for READY).
- **Banners:** Full-width top alerts for Offline/Syncing states.
- **Confirmation Sheets:** Bottom-anchored modals for explicit actions (Accept, Start, Complete).
- **Empty States:** Centered illustration (Navy) + "No assignments" text.
- **Skeletons:** Shimmering neutral blocks for loading lists.

## 4. Cards
- **Assignment Card:** White surface, navy border-left for priority, clear hierarchy of farm, crop, and acreage.
