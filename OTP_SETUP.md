# EOL — Firebase OTP Setup

This Firebase-era setup note is retained only as a historical compatibility redirect. Do not configure Firebase for new environments and do not add Firebase credentials to the repository.

The approved target is an application-owned OTP challenge with WhatsApp-first provider delivery and controlled SMS fallback. Start with [docs/plan/AGENTS.md](docs/plan/AGENTS.md), especially [SPEC.md](docs/plan/SPEC.md), [production_hardening.md](docs/plan/production_hardening.md), and [plan_for_production_rediness.md](docs/plan/plan_for_production_rediness.md).
