HOW TO START THE DaaS-RFLY PLATFORM
===================================

This document provides a simple, step-by-step guide on how to start the application (both frontend and backend).

---

### Prerequisites
1. Ensure Docker is running (for the database).
2. Ensure you have Node.js installed.
3. You will need two terminal/command prompt windows open (one for the backend, one for the frontend).

---

### Step 1: Start the Database
Open a terminal and run this command to start the PostgreSQL database in Docker:
docker run --name rfly-postgres -e POSTGRES_PASSWORD=devpass -e POSTGRES_DB=rfly_daas -p 5432:5432 -d postgres:16

(If it's already running from a previous session, you can skip this step or use `docker start rfly-postgres`)

---

### Step 2: Configure Environment Variables
You need to set up the configuration files before starting the servers.
1. Navigate to the `backend/` folder and copy `.env.example` to a new file named `.env`.
   - Update `DATABASE_URL` if necessary (the default should work).
   - Paste your Firebase Admin keys (`FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`) at the bottom.
2. Navigate to the `frontend/` folder and copy `.env.example` to a new file named `.env`.
   - Paste your Firebase Web keys (`VITE_FIREBASE_API_KEY`, etc.) inside.

---

### Step 3: Start the Backend Server
In your first terminal, navigate into the backend folder:
cd backend

Install the dependencies (if you haven't already):
npm install

Push the database schema (since we added the Farmer role):
npx prisma db push

Start the backend server:
npm run dev

You should see logs indicating the database is connected and the server is running on port 5000.

---

### Step 4: Start the Frontend Server
In your second terminal, navigate into the frontend folder:
cd frontend

Install the dependencies (if you haven't already):
npm install

Start the frontend development server:
npm run dev

You should see a Vite URL (like http://localhost:5173). Open that URL in your web browser.
To test the Farmer Login flow, navigate to: http://localhost:5173/farmer/login
